# تطبيق «دوسياتي» — ملخّصات وأسئلة تفاعلية ( يعمل بدون إنترنت )

## الملفات
`index.html` · `app.js` · `data.json` · `sw.js` · `manifest.webmanifest` · `icon.svg`

## النشر على GitHub Pages ( نفس طريقة تطبيق سجلي )
1. أنشئ مستودعًا عامًّا جديدًا باسم `dosiati` ( أو استخدم مستودعًا موجودًا ).
2. ارفع الملفات الستّة في جذر المستودع.
3. Settings ← Pages ← Source : Deploy from a branch ← Branch : `main` / `root` ← Save.
4. بعد دقيقة يصبح الرابط : `https://<اسم المستخدم>.github.io/dosiati/`
5. الطالب يفتح الرابط مرّة واحدة ، ثم : قائمة المتصفّح ← « إضافة إلى الشاشة الرئيسة » ، فيعمل بعدها بدون إنترنت.

## الاستخدام
- **الملخّص** : شرح الدروس والجداول وبطاقة المصطلحات والقوانين والأخطاء الشائعة.
- **نماذج محلولة** : الحلّ يظهر خطوة خطوة ( زرّ « الخطوة التالية » ).
- **أسئلة** : 26 سؤالًا متدرّجًا ، لكلّ سؤال زرّ « أظهر الإجابة ».
- **اختبر نفسك** : الاختبار كاملًا ؛ الاختيار من متعدّد يُصحَّح فورًا مع توضيح سبب الخطأ ، والأسئلة المقالية فيها مساحة كتابة ثم مقارنة بالإجابة النموذجية ، ومؤقّت 45 دقيقة.
- **للمعلّم** : جدول المواصفات وسلّم التصحيح وملحوظات التصحيح — خلف رمز دخول ، الرمز الافتراضي **2027** ، ويمكن تغييره من داخل القسم ( يُحفظ في جهازك ).
- **وضع العرض** : زرّ في الشريط العلوي يكبّر الخطّ ويملأ الشاشة للعرض على الداتا شو ( أسهم ← → للتنقّل ، Esc للخروج ) ، وزرّا أ+ / أ− لضبط حجم الخطّ في أيّ وقت.

## عند إضافة وحدات جديدة
1. يُعاد توليد `data.json` من ملفات الدوسيات.
2. ارفع `data.json` و `sw.js` بعد رفع رقم الكاش في `sw.js` ( `dosiati-v1` ← `dosiati-v2` ) ليصل التحديث لمن ثبّت التطبيق.

## ملاحظات
- لا يُرسل التطبيق أيّ بيانات إلى أيّ خادم ؛ تقدّم الطالب ورمز المعلّم محفوظان في جهازه فقط ( localStorage ).
- يعمل على الهاتف واللوح والحاسوب ، ويدعم الطباعة ( الإجابات تظهر عند الطباعة ).
